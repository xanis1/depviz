# depviz

CLI-инструмент визуализации графа зависимостей для менеджера пакетов npm.
Вся логика получения метаданных и обхода графа написана самостоятельно
на стандартной библиотеке Python, без менеджеров пакетов и сторонних
библиотек.

Проект разрабатывается поэтапно (этапы 1-5), каждый этап фиксируется
отдельным коммитом.

## Запуск (Windows)

    run.bat <параметры приложения>
    run.bat test
